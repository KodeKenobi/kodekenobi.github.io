Install ActiveDesk on macOS

Step 1: Download the installer

Download install-activedesk.command

The file will be saved to your Downloads folder

Step 2: Open Terminal

Press Command + Space to open Spotlight search, type Terminal, then press Enter.

Step 3: Run the installer

Copy and paste this command into Terminal, then press Enter:

chmod +x ~/Downloads/install-activedesk.command && ~/Downloads/install-activedesk.command

Step 4: Follow the installer

The installer will:

  • Download the latest ActiveDesk (around 111 MB)
  • Verify the files are safe
  • Install to your Applications folder
  • Open ActiveDesk automatically

Security warning?

If you see "Cannot verify developer" when opening Terminal or ActiveDesk, that is normal. Click Open in the dialog.
